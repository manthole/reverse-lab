# Analyses

Un dossier par échantillon analysé, nommé `AAAA-MM-JJ_famille` (par exemple
`2026-11-12_agenttesla`), contenant le rapport (à partir de
[`modeles/rapport-analyse.md`](../modeles/rapport-analyse.md)) et ses captures.

**Ne dépose jamais l'échantillon lui-même ici**, même dans une archive chiffrée : le dépôt est
public. Son empreinte SHA-256 suffit pour le retrouver sur MalwareBazaar.
